# IRIX 5.3's wd93 driver negotiating with the WD33C93A, captured from IRIS.

# Captured 2026-09-01 for sgiindy_MiSTer docs/23-init-divergence.md, with
#   iris --config iris-diff.toml   +  monitor: log scsi on / log scsi file ...
# on the same disk image and PROM the DE10-Nano boots. This is the REFERENCE
# for what the driver programs into the chip - not for what a target should
# answer, which IRIS cannot tell you: it has no bus-level target, so it
# swallows the MESSAGE OUT bytes and never presents a MESSAGE IN reply.
#
# The sequence below repeats ~3180 times over a boot: Select-with-ATN (0x06),
# then Transfer Info (0x20) with a transfer count of SIX in MESSAGE OUT.
# Six bytes is IDENTIFY (1) + SDTR extended message (5), which is the
# negotiation the board answers badly enough that IRIX prints
#   NOTICE: wd93 SCSI Bus=0 ID=1: SYNC negotiation error, resetting bus
#
# Chip status codes the driver is waiting on, in order:
#   0x11  selection complete
#   0x8E  MESSAGE OUT phase requested   (ST_REQ_SMESGOUT)
#   0x8A  the MESSAGE OUT transfer finished
#
